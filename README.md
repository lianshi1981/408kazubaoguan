# 游戏王 408 环境卡组资料库

这是可直接部署的静态网站成品，入口为根目录的 `index.html`。

保留卡组浏览、名称搜索、分类、详情、卡图放大和 YDK 下载。无需运行 Python、Django、数据库或云函数。

## 部署

把本仓库作为静态网站发布即可，不需要安装依赖或编译。若平台要求填写构建命令，可填 `exit 0`；发布目录选择仓库根目录。

文件使用相对路径，同时支持域名根目录和 GitHub Pages 的仓库子目录。

## 更新卡组

在电脑上的原始项目中管理卡组并重新生成静态发布包，然后将新成品同步到本仓库。更新时应删除旧成品中已经不再使用的文件，避免已下架卡组仍能通过旧下载链接访问。

公开页面不提供管理员登录、上传或删除入口。

## 文件结构

- `index.html`：网站入口。
- `assets/`：页面样式、程序和用到的卡图。
- `data/decks.json`：卡组资料。
- `downloads/`：原始 YDK 卡组文件。
- `.nojekyll`：GitHub Pages 静态文件标记。

本站为玩家制作的非官方资料库。卡图版权归原权利人所有，卡组规则请以使用的禁限卡表为准。
